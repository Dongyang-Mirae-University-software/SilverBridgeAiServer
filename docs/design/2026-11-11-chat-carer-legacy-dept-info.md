## 판정 순서 (불변)

응급 → 자해 → 위험 신호 → 진료과 고정 답 → 예약 → 단계 되묻기(WARD) / 옛 되묻기(보호자) → 상담. ③은 상담 단계의 생성 의도만 바꾼다(응급이면 `emergency_guidance` 그대로).
