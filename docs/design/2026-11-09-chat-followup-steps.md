# 의료 상담 되묻기 - 한 번에 한 질문 (2026-11-09)

## 배경
짧은 증상 한마디("머리가 아파요")에 되묻기 답이 질문 3개·진료과 줄·마무리 줄(7줄 164자, 줄마다 이모지)과 칩 4개를 한꺼번에 보였다.
어르신은 다 읽거나 한 번에 답하기 어렵다.

## 결정 (사용자 승인 2026-11-09)
| 항목 | 결정 |
|---|---|
| 질문 수 | 최대 3개: 위험 신호 → 언제부터 → 묶음별 동반 증상 |
| 한 턴 | 질문 1개(22자 이하) + 답 버튼 2~3개("네"/"아니요", "오늘부터요"/"며칠 됐어요"/"오래됐어요") |
| 위험 신호 "네" | 머리·어지럼·저림·배·기침·숨/가슴 묶음 = 규칙 응급 답(119·경고 박스) / 관절·기본 묶음 = 오늘 진료 권유 |
| 보호자 대리 상담 | 같은 흐름, 돌보는 사람 말투 질문·버튼 |
| 결과 답 | 모델 문장 3개·120자(피보호자 간결 규칙을 이 결과 턴에는 보호자 경로에도) + 서버 고정 문장은 그대로 |
| 이모지 | `CHAT_LAYOUT_EMOJI`(기본 false) - 모든 줄 머리 이모지를 뺀다. 응급 핵심 줄은 119 전화 문장(없으면 "119에 바로 전화하세요.") |

## 흐름
- 질문 턴은 MedGemma 0회(고정 표 `app/services/followup_steps.py`). 라우터는 매 턴 그대로 돈다(응급·자해 판정).
- 판정 순서는 그대로: 응급 키워드·라우터 응급·자해·위기·예약·진료과 질문이 단계 처리보다 먼저.
- 자유 입력 해석: 네/아니요·기간 답은 지금 질문의 답 / 다른 질문의 답·새 증상·긴 설명은 남은 질문을 건너뛰고 결과 /
  짧은데 못 알아들은 말은 같은 질문을 한 번만 다시(두 번째는 모름으로 넘어감) / "모르겠어요"는 모름 / 인사·"그만"은 흐름 종료(지금 규칙).
- 위험 신호 질문에 짧고 분명한 "아니요"로 답하지 않고 결과에 온 답에는 그 묶음의 119 기준 한 줄을 넣는다.
- 위험 신호 낱말이 있는 첫 문장("숨이 좀..")은 첫 턴에 지금의 119 한 줄을 그대로 함께 보낸다.
- 진행 상태: 서버가 쓴 직전 기록 `upstreamMeta.followupStep`(묶음·순번·답 문장 조각·다시 묻기·대리·턴 수)만 읽는다. 클라이언트 값은 보지 않는다.
  옛 기록(followupStep 없음)은 옛 한 번 되묻기 흐름 그대로.
- 결과 턴 MedGemma 입력: "증상 / 답 / 답 / 답"(옛 "앞 질문 / 이번 답"과 같은 꼴).
- 바뀐 점: 질문 턴의 진료과 줄은 결과 답으로 옮겼다(질문 턴은 질문 하나만).

## 바뀌지 않는 것
응답 칸 구조(layout 5칸·`suggestedQuestions`·`suggestedKind="answer"`), BE 허용 목록, 응급·자해·위기 답 문장, `followupAsked` 메타.
