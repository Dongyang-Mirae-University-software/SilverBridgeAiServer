# 2026-11-18 지시문 노출 문장 제거 보강

## 문제
- 앞 턴 없이 생성한 기침 칩(F1 측정)에서 관리 질문 줄의 지시 문장("답을 짧게 써야 할 때도 이 첫 문장은 빼지 않고…",
  "이 질문은 증상이 있을 때 무엇을 먹거나…")과 약 질문 규칙("약을 더 먹어도 되는지, 몇 알인지 … 끊으라고도 하지 마라.")이
  최종 답에 그대로 나갔다.
- 기존 `drop_prompt_leak`(I-3)은 `advice`·`규칙 N`·칸 이름 같은 정해진 낱말만 찾아, 그런 낱말이 없는 지시 문장은 못 걸렀다.

## 변경
- `instruction_text()`: 시스템 프롬프트 규칙(예시 답 제외) + 사용자 프롬프트 지시 줄 + 관리 질문 줄 + 피보호자 간결 줄에서
  따옴표 안 권장 문장(모델이 써도 되는 "…꼭 진료를 받아 보세요." 같은 것)을 뺀 지시 문장 묶음.
- `drop_prompt_leak`: 기존 낱말 규칙에 더해, 공백·문장부호를 뺀 **20자 이상이 지시 문장과 그대로 같은 문장**도 뺀다(문장 단위).
  고정 문장 추가 없음, 서버가 뒤에서 붙이는 고정 문장은 이 단계 뒤라 영향 없음.

## 검증
- 단위: 노출 3문장은 빠지고 정상 7문장(예시 문장·서버 고정 문장·진료 권유 포함)은 남는다(`tests/test_prompt_instruction_leak.py`).
- DGX 회귀(라우터 stub, Claude 0): 관리 질문 30 + 칩 must 27 + v6 88 + v5 36 + v7 응급·위기 49 = 230문항. 생성은 그대로라
  달라지는 것은 빠진 문장뿐 - **새 규칙으로 빠진 문장 1건(약 질문 규칙 문장 노출, 실제 노출)·정상 문장 오탐 0건**.
- pytest 전체(gosky .venv 사본) 4,249 통과.
