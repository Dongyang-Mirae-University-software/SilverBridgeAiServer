# 라우터 실패 때 키워드 분류 응급 누락 점검·수정 (2026-11-06)

- 배경: 2026-11-04 크레딧 소진으로 라우터가 실패한 동안 v4 대조군 응급 4문항 중 3개가 119·경고 박스 없이 나갔다(main 도 같음).
- 방법: 코드 읽기 + 기존 시험지 전체를 라우터 실패 조건(키워드 경로)으로 재분류(문항 id·개수만), 합성 반례. API 미사용.

## 흐름

라우터 예외(`chat_service` `[CHAT-ROUTER-FAILED]` WARN) → 키워드 경로(`_keyword_route` - 이번에 함수로 뺌) → `_force_emergency`. 라우터가 실패하면 응급 근거는 `chat_keywords` 하나뿐이고 라우터 칸(`emergency`·`cardiac_arrest`·`urgent_condition`)을 대신하는 것이 없었다.
