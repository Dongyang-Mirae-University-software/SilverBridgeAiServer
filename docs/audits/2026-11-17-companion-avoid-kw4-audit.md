## 이슈

### 🟠 H-1 피하는 말 새 패턴 오탐 - 일상 대답이 대화를 일찍 끝낸다
- 실서버 S4에서 확인. `(알아|들어|물어)서\s?뭐\s?(해|…)`가 "혼자 **알아서 뭐 해** 먹었지"(스스로 해 먹었다)를, `(말|얘기|이야기)해서\s?뭐\s?(…할)`·`(말|얘기|이야기)\s?해서\s?뭐`가 "얘기해서 뭐 할지 정했어"(의논해서 정했다)를 잡는다. 두 번이면 `AVOIDED`로 끝나고 보호자 기록에도 남는다.
- 같은 꼴로 정규식만 대 본 오탐: "말 꺼내기도 전에 다 알아서 해 주더라"(`(말|얘기)\s?꺼내기도`), "내 속은 내가 알지 요즘 소화가 안 돼"(`속`=배), "병원에 뭐 하러 물어보러 갔나 몰라", "그런 얘기 그만 좀 하라고 했지"·"누구한테 묻지 말고 병원 가래"(전해 들은 말), "좋은 얘긴데 뭘", "시장 들어서 뭐 하게".
- DGX 실제 어르신 대답 2,446개에서는 새 오탐이 0이어서 빈도는 낮을 수 있으나, "점심 드셨어요?"에 "알아서 해 먹었지"는 흔한 대답 꼴이다.
- 수정 방향: `알아서`는 패턴에서 빼거나 끝맺음(`알아서 뭐 해$`·`알아서 뭐 하게`)만 / `해서 뭐`는 뒤에 `할지·먹·하기로` 같은 이어짐이 오면 제외 / `꺼내기도` 뒤 `전에` 제외 / `내 속은`은 `(나만|내가)\s?(알|안다)$`처럼 끝맺음만 / 전해 들은 말(`-라고 했`·`-래`·`-더라`)을 `OTHER_PERSON`류 제외에 추가. 오탐 문장을 아닌 말 테스트로 고정.

### 🟠 H-2 kw4 부정 제외가 이중 부정 "않을 리가 없"을 놓친다 (#305 회귀)
- "죽고 싶지 않을 리가 없지"(=죽고 싶다)는 #305 전 kw4가 `죽고 싶`으로 잡았으나 지금은 `NEGATED_DEATH_WISH`가 지운다. r2도 0.06이라 **두 경로 모두 놓친다**.
- "않은 날이 없어"·"않은 적이 없어"도 낱말로는 놓치지만 r2가 0.99 이상으로 잡는다(어댑터가 꺼지면 놓침).
- 수정 방향: 부정 예외 앞보기에 `을\s?리가\s?없`·`은\s?(날|적|때)이\s?없` 추가 + 테스트 고정. (기준표의 🔴은 '위험 놓침'이나, 표현 하나에 한정되고 다른 낱말·어댑터 경로는 그대로라 High로 둔다)

### 🟢 L-1 "살기도 싫어"는 낱말 목록에 없다 (기존)
- `살기 싫`은 있지만 조사 `도`가 끼면 안 걸린다(#305 커밋 주석의 "…않은데 살기 싫어는 따로 걸린다"는 붙은 꼴에서만 맞다). r2가 0.996으로 잡아 실제 놓침은 없다. 낱말 목록 변경은 재희 규칙 범위라 기록만.
