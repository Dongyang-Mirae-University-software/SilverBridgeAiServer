## 이슈

- 🟠 **H-1 생성 실패 대체 응답에 응급 행동 줄이 없다** - 응급 턴은 MedGemma 대기 3초라 동시 상담·지연 때 `_fallback_reply`의 고정 문장("119 또는 가까운 응급실")만 나간다. 심정지(키워드든 라우터 칸이든)여도 가슴압박·AED 줄이 빠진다(#159부터 같은 빈틈, #174로 대상이 넓어짐). 수정안: 응급 대체 응답에도 `emergency_action_sentences(message, carer, arrest_hint)`를 붙인다 + 테스트.
- 🟡 **M-1 서버의 "의식 있음" 판단이 현재 의식 표현을 못 본다** - `arrest_conscious`는 추측·회복 표현만 보고 "지금 말은 해요·대답해요·눈 떴어요·숨 쉬어요" 같은 현재 의식 표현은 못 알아본다. 라우터가 오판하면 의식 있는 사람에게 가슴압박 줄. 수정안: 현재 의식 표현을 추가 + 테스트.
- 🟢 L-1 경계 질환 문장이 대체 응답·되묻기 다음 턴에 안 붙는다(경계 질문은 대개 긴 문장이라 영향 작음).
- 🟢 L-2 항응고제 머리 부딪힘 문장이 NHS보다 한 단계 강함 - NICE의 항응고제 두부 외상 CT 권고와는 맞아 수용 권장.
- 🟢 L-3 테스트 공백: 대체 응답 경로·현재 의식 표현.
