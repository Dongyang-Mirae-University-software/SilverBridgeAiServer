## 이슈

- 🟠 **H-1 알약 제외가 진짜 삼킴 곤란·질식까지 뺀다** - `_PILL_FORM`이 있고 `_AIRWAY_DISTRESS`(숨·말·얼굴색·컥컥…)가 없으면 `목에걸려`를 지우는데, 침을 못 삼키거나 흘리는 말과 음식 낱말을 보지 않는다. 실서버에서는 라우터가 응급으로 잡았지만 라우터 실패·응급 키워드 기반 라우터 대기 단축(15초)·`_force_emergency` 보장을 잃는다. 수정안: 거리 낱말에 `침(을|도)?(못|안)삼|침을흘|못삼켜|삼키지못|안넘어가` 추가, 음식 낱말(떡·사탕·고기·밥·생선·가시·과자·견과·음식)이 있으면 제외하지 않음 + 테스트.
- 🟡 **M-1 "숨이 멎을 만큼" 관용구가 응급 + 가슴압박** - 새 키워드 `숨이멎`·`ARREST_SIGNAL`이 비유 표현을 가리지 않는다. 수정안: `숨이멎` 뒤 `을(만큼|듯|것같|뻔)|는줄` 이면 신호에서 뺀다 + 테스트.
- 🟡 **M-2 의식 있는 사람의 추측·회복 표현에 가슴압박 줄** - `ARREST_SIGNAL`의 `정신을잃`·`의식을잃`·`의식이?없`이 "잃을 것 같아요"·"잃었다가 깼어요"에도 맞아 쓰러짐 줄 대신 가슴압박 줄이 붙는다(문장이 조건형이라 해롭지는 않지만 맞지 않는 안내). 수정안: 추측(`것같|듯|뻔|어질`)·회복(`다가(금방)?깼|었다가`) 표현이면 심정지 신호에서만 뺀다(응급 키워드는 유지) + 테스트.
- 🟢 **L-1 라우터 실패 때 알약 삼키기 질문이 일반 대화** - 키워드 분류에 `알약·서방정·캡슐` 낱말이 없다(#159 전에는 오탐으로 응급). 상담 낱말 보완 후보.
- 🟢 **L-2 맥락 없는 "불러도 대답이 없어요"·"깨워도 안 깨요"·"숨을 안 쉬고 참으면"은 응급** - 안전 쪽 오탐으로 수용 권장(기록만).
- 🟢 **L-3 테스트 공백** - 라우터 실패 경로(키워드 분류)와 되묻기 다음 턴(앞 질문 위험 신호 → 119 줄) 회귀 테스트가 없다.
